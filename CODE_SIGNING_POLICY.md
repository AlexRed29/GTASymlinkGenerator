# Code Signing Policy

## Project
**GTA Symlink Generator**
GTA Symlink Generator is an open-source Windows utility for creating symbolic links and copying required files for supported Grand Theft Auto installations and mods.

## Code Signing
Free code signing provided by SignPath.io, certificate by SignPath Foundation.
Releases of GTA Symlink Generator may be digitally signed to allow users to verify the authenticity and integrity of the distributed binaries.

## Source Code
The source code and build configuration of GTA Symlink Generator are publicly available in this repository.
Signed binaries must be built from the source code contained in this repository through the project's documented build process.

## Release Process
Each release is reviewed before signing.
Only binaries produced from the project's source code and build process may be submitted for signing.
The project maintainers are responsible for the source code, build configuration, and release artifacts.

## Certificate
The code-signing certificate provided through SignPath Foundation is used exclusively for signing official GTA Symlink Generator releases.
Private signing keys are not stored in the source code repository.

## Changes
Significant changes to the project's build or release process will be documented in the repository.
